# Spatia Wallet - Cross-Platform Mobile DePIN Client

Institutional-grade, high-performance Flutter Web3 Wallet with:
- Native Custom Candlestick Painter (120 FPS zero-lag canvas)
- Autonomous Multi-DEX Routing and DePIN Hardware Proof-of-Presence
- GitHub Actions CI/CD for automated zero-cost APK compiling

## Quick Start (Compile via GitHub Actions)
1. Push this repository to GitHub (`git push origin main`).
2. Go to the **Actions** tab in your GitHub repository.
3. Wait ~3-4 minutes for the **Build Spatia Wallet APK** workflow to finish.
4. Download the generated `SpatiaWallet-Release-APK` artifact directly to your Android phone!
